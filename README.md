# HSK pinyin trainer

Live: <URL to be filled>

A self-contained HTML app for learning HSK 1–4 pinyin: sounds, tones, and the pronunciation of ~1200 HSK 1–4 vocabulary words. No backend, no build tooling required to run — open `index.html` directly in a browser, or visit the live GitHub Pages URL above. All data and logic are inlined, so once the page has loaded it keeps working offline; the one exception is the Google Fonts `<link>` (falls back to the system font if unreachable, so the app still works, just without the custom typeface).

This repository publishes only the pinyin trainer. A sibling character trainer (`hsk_characters.html`) exists in the local working copy but is excluded via `.gitignore` and is not part of this public repo.

## Files

- `index.html` / `hsk_pinyin.html` — **the app**, identical self-contained builds (`index.html` exists so GitHub Pages serves it at the site root). Data and helpers are inlined. Open directly from `file://` or serve as static files.
- `src/pinyin_app.html` — dev version of the app. Loads `data/hsk_vocab.js`, `data/pinyin_lessons.js`, and `src/pinyin_core.js` via `<script src>` so they can be edited independently. Also works from `file://`.
- `src/pinyin_core.js` — pure-JS pinyin helpers (syllable split/marking, valid-syllable table, distractor generation, type-answer normalization, placement scoring, progress-shape validation). No DOM dependency; usable from both the browser and Node.
- `data/hsk_vocab.js` — `const VOCAB=[{w,py,n,en,lv}]`, HSK 1–4 vocabulary (~1200 words). Regenerated by `tools/build_vocab.py` (see its docstring for the source dataset, sense-selection rules, and the manual override table).
- `data/pinyin_lessons.js` — `const LESSONS=[...]`, the 12-lesson "Sounds" curriculum.
- `build.sh` — inlines `data/hsk_vocab.js`, `data/pinyin_lessons.js`, and `src/pinyin_core.js` into `src/pinyin_app.html`, producing `hsk_pinyin.html` and a copy at `index.html`.
- `tests/pinyin_checks.js` — Node script exercising the real helpers against the real data (see below).
- `docs/PINYIN_SPEC.md` — design spec for the pinyin trainer (source of truth for behavior; deviations noted at the bottom).

## Build

```
./build.sh
```

Regenerates `hsk_pinyin.html` and `index.html` from the current `src/` and `data/` files. Requires only `awk` (no Node needed to build, though Node is used for checks).

## Run

Open `index.html` (or `src/pinyin_app.html` for development) directly in a browser — no server needed. Progress is stored in `localStorage` (or `window.storage` if the host page provides that shim).

## Deploy

GitHub Pages is configured to serve from the `main` branch root. Deploying is: run `./build.sh` to refresh `index.html`, commit, and push to `main` — no separate deploy step or CI action.

## Checks

```
/opt/homebrew/bin/node tests/pinyin_checks.js
```

Runs, against real `data/` files:
1. `mark(n) === py` for every `VOCAB` entry (tone-mark placement + apostrophe-boundary rule), reporting any mismatches.
2. Distractor generation over 200 random words — every distractor is a valid, distinct syllable string that isn't the answer and has the same syllable count.
3. `normType`/`acceptTypeAnswer` accepts the documented input variants (numbered, marked, mixed case, `ü`/`v` equivalence, omitted/`0` neutral tone) and rejects wrong tones.
4. Placement strata bucket math (8 foundation + 40 vocab = 48 items across 16 buckets), via the shared `PC.strata`.
5. Erhua regression: 一会儿 (a trailing bare "r" syllable) gets real tone-swap distractors, not the rule-4 different-word fallback.
6. No distractor puts a neutral (5th) tone on a word's first syllable, checked across the full corpus.
7. `validateProgShape` rejects malformed imports (`null`-valued `w`/`sets`/`lessons`, a bare array) and accepts a real export shape.
8. `placementStopIndex`'s rolling-window pass rule on synthetic bucket results (all-correct passes everything; an all-wrong bucket stops there; a single miss in a big-enough bucket still passes).

Current result: **0/1193 mark() mismatches, all 8 checks pass.**
